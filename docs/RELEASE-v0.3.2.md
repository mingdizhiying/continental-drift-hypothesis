# 大陆漂移假说 v0.3.2

本次 Release 汇总自 v0.2.0 以来的游戏机制与界面更新。

## 在线试玩

https://continental-drift-mingdizhiying.mingdizhiying.chatgpt.site

无需账号或模型密钥，采用本地规则模拟。刷新页面会重新开局，请先导出需要保留的历史。

## 本次更新

- **随机旋转领地**：六城每局独立随机俄罗斯方块形状、朝向、旋向与角速度；地图显示真实领地和交叠范围。
- **资源争夺与贸易**：重叠按面积产生资源损失；未重叠且边界一格以内大量贸易。
- **外交调停**：消耗8繁荣并推进一轮，指定双方休战三轮，暂停彼此冲突与贸易。
- **圣光屏障与统一资源**：恢复城内抉择与三种旧誓约，治理与屏障共用粮食、安定、繁荣、生态，任期产生共誓、孤光或长夜结果。
- **每轮回响弹窗**：市民事件、关系切换和任期提醒合并弹出，持续互动与历史默认折叠，减少页面长度。
- **结算置顶**：第60轮结束后，结算位于页面主内容最上端，关闭最终回响自动定位。

六轮自动迁往最近其他城市、允许返回旧城、每城一条持续誓约、完整历史导出等规则保留。

## 下载与运行

- `continental-drift-v0.3.2-static.zip`：仅包含公开静态试玩资源与启动说明，适合静态托管；解压后通过HTTP服务访问，不能直接双击HTML运行模块脚本。
- GitHub自动提供的 Source code：完整源码；需Node.js 24或更高版本，运行 `npm start`，不需安装第三方依赖。
- `SHA256SUMS.txt`：静态包校验值。

## 验证与限制

35项规则测试通过，包含8种随机世界各60轮的边界与结算检查；语法检查、静态构建及git diff --check通过。浏览器自动化环境故障，实际点击、键盘焦点和手机视觉尚未验证。

这是可试玩原型：本地誓约为关键词映射，真实模型尚未使用供应商凭据联调；暂无存档恢复、程序化地质模拟或运行时代码热更新。数值仍待试玩平衡。

Release指向独立验证的发布提交，不代表所有历史PR已合并到main。完整阶段记录见CHANGELOG.md。
