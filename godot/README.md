# Godot 运行版

在 Godot **4.7.2** 项目管理器中导入本目录的 `project.godot`，打开后按 **F6** 运行当前主场景，或按 **F5** 运行项目。默认完整离线运行，不需要启动 Node.js、不需要安装插件。字体使用系统中文字体，不依赖在线字体服务。

已完成对网页v0.3.2的三个阶段迁移，进度与验证记录见 [MIGRATION.md](MIGRATION.md)。包括八种治理行动、五种守护与三种旧法则、屏障与任期结果，以及随机四格板块、旋转、真实几何重叠、资源争夺、封顶贸易和三轮外交休战。板块允许穿过，不阻挡或合并；迁移仍按中心距离选择，允许反复返回旧城。

右侧固定显示城市指标，下方分为“治理 / 誓约 / 领地外交”三页。治理卡片直接显示法则调整后的成本、收益与不足原因；誓约需要预览再确认。每次成功行动只弹出一个世界回响，统一展示事件、关系切换与原因、任期结果和迁城提醒；持续互动默认折叠。关闭、继续或Esc均可关闭弹窗，焦点返回查看入口；查看、立誓和失败行动不弹回响。世界历史默认折叠，可手动展开。第60轮关闭最终回响后，主内容顶部显示结局和六城结果，可再打开完整证据窗口。

## 迷雾与灯塔（Godot 扩展）

- 默认只显示当前治理城市的领土，与其实际接触（包括角点接触）或重叠的其他领土，以及有效贸易城市的中心点。接壤不等于一格贸易范围，视野不会通过邻城继续传播。
- 贸易中心不显示板块和城内信息；接壤领土可以观察形状，但城内指标、誓约与操作面板不开放。隐藏城市的按钮、连线、起点位移和下一站预测同样隐藏，选中邻城不会改变观察者。正常回响/历史只展示玩家经历及与其治理城市有关的互动，远方AI世界摘要不直接绕过迷雾。结束后可完整复盘。
- 治理页可以一次性支付**繁荣20、粮食5、生态3**永久点亮本城灯塔，**不推进轮次、不触发事件**。资源不足或已点亮时不支付、不改变状态。费用与是否启用迷雾可在`data/world.tres`的WorldConfig检查器修改。
- 灯塔固定**点亮时的城市中心与朝向**，中心和旋转都永久停止，离任后仍生效；不会自动替换原有誓约，旧的位置誓约也不能把城市拉回更早坐标。世界其他城市、贸易/争夺和六轮迁城仍照常运行。
- 点亮后立即获得当前轮的全图视野。查看、切换、立誓、失败操作不消耗；**下一次成功行动结算后恢复迷雾**。返回已点亮城市不再次获得全图，也不能重复点亮刷新视野。灯塔不持续照亮远方。
- 灯塔、支付、坐标/朝向锚点和全图视野轮次保存在运行状态、灯塔快照与完整JSON导出中；本局永久，重新创造世界清空。当前仍无读档，关闭游戏不保存进度。
- “完整世界记录”导出用于复盘/调试，包含迷雾中未显示的数据；它不是玩家视野的脱敏导出。网页v0.3.2本身没有此扩展，固定参考引擎保持原样。

## 在编辑器里改什么

| 文件 | 编辑入口 |
| --- | --- |
| `scenes/main.tscn` | 主界面容器、按钮、面板和弹窗；节点保存在场景中 |
| `scenes/world_map.tscn` | 地图容器和城市显示层 |
| `scenes/city_view.tscn` | 四格板块的显示样式、城市标记和标签；实际几何由规则生成，显示与判定使用同一组点 |
| `scenes/metric.tscn` | 城市指标文字与进度条 |
| `scenes/action_card.tscn` | 治理卡片标题、支付、收益和不足原因的布局 |
| `scenes/echo_dialog.tscn` | 回响模态窗口、内部滚动、互动折叠和继续按钮 |
| `theme/atlas.tres` | 所有面板、按钮、字体与颜色的统一主题 |
| `data/world.tres` | 在检查器展开 Cities、Actions、Events，调整城市初始位置/速度/指标/颜色、行动效果与事件文案/效果/优先顺序 |
| `scripts/world_rules.gd` | 回合执行顺序、漂移、誓约保护、事件条件、迁移和结局规则 |
| `scripts/city_economy.gd` | 完整支付、旧法则的行动成本/收益、失败原因及屏障结果 |
| `scripts/territory_rules.gd` | 与网页一致的uint32随机序列、七种形状、双精度旋转多边形求交、面积和边界间距 |
| `scripts/world_vision.gd` | 地图、选城、详情、连线及回响共用的视野与展示规则 |
| `scripts/main.gd` | 玩家输入、选城、预览确认、界面刷新、导出与异步请求协调 |
| `scripts/echo_dialog.gd` | 本轮事件、关系原因、任期提醒和可折叠互动汇总 |
| `scripts/ai_client.gd` | 本地代理地址与请求超时；默认 `http://127.0.0.1:4173/api/world` |

`data/world.tres` 使用四种自定义 Resource：CityDefinition、ActionDefinition、CitizenEventDefinition、WorldConfig。运行时复制资源生成 Dictionary 状态，不会把游玩结果写回初始资源。规则状态与地图节点分离；地图缩放和动画不会改变距离或结算。

地图标签避让，城名按钮只列当前可见城市，中心点模式不可打开详情；板块重叠时仍能分别观察。仅当前治理城市允许行动、点灯或立誓，行动完成后选中城市跟随迁移。治理卡片显示实际成本与收益，悬停可查看场所和全部资源不足原因。

主场景根节点的`initial_seed`默认为-1（每局随机）；在检查器填入0–4294967295中的整数，可复现与网页同种子的形状、朝向和旋速。领地页显示各城关系、间距和重叠比例，外交目标只包含当前重叠且未休战的城市。规则几何保持双精度，转为Vector2仅用于显示；不会以物理碰撞或外接矩形替代领地求交。

### 修改边界

- 当前以六座城市、八种治理行动为基线。行动资源中的cost/gain驱动支付、按钮说明和历史；新增城市/行动后，需要同时调整界面、代理校验和对照测试。
- 事件的 `predicate` 对应 `WorldRules.event_matches()` 中的已实现条件。修改说明文案不改变判定；新条件需补充脚本。
- 位置誓约恢复时回到**立誓坐标**；数值誓约按轮初条件生效，以轮初指标减主动支付成本为下限，不能返还建设或公开秘密成本。
- 真实 AI 的追加影响在本地迁城判定之后处理，与网页原型一致。
- 地图为四格领地玩法，已加入迷雾与灯塔；尚无独立地形、美术贴图、代码热更新或存档恢复。关闭程序或重新创造世界会清空进度；JSON导出供复盘，不能作为读档导入。

## 真实 AI（可选）

Godot使用与迁移基准配套的独立代理。按根目录 README 配置 `.env` 后在仓库根目录运行：

```sh
node --env-file=.env tools/godot-proxy.mjs
```

再在右侧“誓约”页勾选“使用真实 AI 接口”。誓约、回合和结局使用相同的三类请求。密钥只在代理环境中；Godot工程不保存供应商密钥。回响和底部状态明确显示本轮AI结果或本地回退，最终AI文字不会覆盖本地六城屏障证据。

无法连接、503、超时或数据格式错误都会显示原因并使用本地规则；AI 明确拒绝誓约时不改为本地接受。客户端再次校验保护类型、条件、城市 ID、重复影响和每指标 ±3 的整数范围，不能突破生效誓约。

**验证状态：**Godot客户端使用假代理验证HTTP协议、拒绝和回退；实际`godot-proxy.mjs`另以本地假模型服务验证八类誓约、结果校验、越界/重复影响和仅第60轮结局。未使用真实供应商凭据，不代表真实模型效果已验证。

## 验证

在仓库根目录执行；需要 Node.js 24 和 Godot 4.7.2：

```sh
npm test
npm run check
npm run test:godot -- /absolute/path/to/godot
```

Windows 示例：

```powershell
npm run test:godot -- 'D:\godot\Godot_v4.7.2-stable_win64.exe'
```

脚本生成被Git忽略的参考数据，依次执行网页参考引擎35项测试、真实代理的假模型服务测试、资源导入、45组3088次操作的JS/GDScript逐轮对照、完整UI流程和Godot客户端假代理测试。对照覆盖支付拒绝、八类誓约、动态成本、AI保护与任期复核、8种随机世界、uint32边界种子、重叠/接壤/一格阈值、三轮休战、第三城冲突和贸易封顶；每轮比较城市、实际几何、外交、成本、历史与结局。

## 维护原版基线

`tools/web-baseline/` 保存已注明提交来源的网页引擎快照，用于对照和可选代理；根目录网页文件保留原样。`node tools/export-godot-data.mjs` 从此快照重新生成 `data/world.tres`。**它会覆盖手动调整后的资源**，仅在有意更新基线时运行，正常游戏和测试不会覆盖。
